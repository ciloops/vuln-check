vuln-check Docs Releases GitHub

Vulnerability truth for AI agents.

Runs grype locally, overlays OSV, and returns a prioritised answer with concrete upgrade targets instead of a 40 KB JSON dump.

Install

brew install grype
go install github.com/ciloops/vuln-check/cmd/vuln-check@latest
vuln-check scan .
# or: brew install ciloops/tap/vuln-check · npx @ciloops/vuln-check scan .

CLEAN (~20 tokens) · REVIEW (all scores < 40) · ACTION_REQUIRED
actions
Smallest version per package that closes every finding, with a breaking flag.
score
0–100 from CVSS, EPSS, CISA KEV and fix availability.
fresh
Advisory came from OSV before grype-db ingested it.

CI

  with: { target: ., fail-above: 69, sarif: vuln.sarif }

Scope

npm, PyPI, Go, Maven, Cargo, RubyGems, Composer, NuGet, Hex, Pub, Swift, R, Conan, OS packages, container images, SBOMs. Runs locally; only the optional OSV query (--no-osv to disable) touches the network.
